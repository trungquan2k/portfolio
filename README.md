# IAMQUAN · 360° Mobile Developer Portfolio

Immersive orbital portfolio — drag to spin around a holographic phone and click glowing nodes for experience, skills, projects, and contact. Not a scroll page.

## Run

```bash
npm install
npm run dev
```

## Customize

Edit content in `src/data/portfolio.ts` (brand, hotspots, positions, accents).

## Stack

Vite · React · TypeScript · Three.js · React Three Fiber · Drei · Postprocessing
